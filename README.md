# Wordle Telegram

Telegram bot for playing Wordle

## Stack

- TypeScript & Deno
- grammY as a core framework
- SQLite as a database
- Biome as all-in-one codestyle enforcer

## Development

```sh
cp .env.template .env
deno task dev
```

Useful tasks:

- `deno task check`
- `deno task format`
- `deno task render:sample`
